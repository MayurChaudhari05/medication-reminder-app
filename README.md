# Medication Reminder App

## Description

This is a Python application that reminds users to take their medicines at a specific time.

## Features

* Add medicine with time
* Get notification reminder
* Simple GUI using Tkinter

## Technologies Used

* Python
* Tkinter
* SQLite
* Plyer

## How to Run

1. Install libraries:
   pip install plyer schedule

2. Run the app:
   python times.py
